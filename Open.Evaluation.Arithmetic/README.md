# Open.Evaluation.Arithmetic

Arithmetic operators for the Open.Evaluation family: `Sum`, `Product`, and `Exponent` over generic numeric types, plus catalog extensions for parsing formulas, and for generating mutations and variations of existing arithmetic formula trees. Built on [Open.Evaluation.Core](https://www.nuget.org/packages/Open.Evaluation.Core); see also [Open.Evaluation.Boolean](https://www.nuget.org/packages/Open.Evaluation.Boolean) or the [Open.Evaluation](https://www.nuget.org/packages/Open.Evaluation) metapackage for both.
