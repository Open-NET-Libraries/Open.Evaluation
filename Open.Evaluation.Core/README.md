# Open.Evaluation.Core

Foundational abstractions for the Open.Evaluation family: the `Catalog<T>` that owns and deduplicates evaluation nodes, the evaluation `Context`, and the base operator/parameter/constant types that hierarchical formula trees are built from. It has no operators of its own — pair it with [Open.Evaluation.Arithmetic](https://www.nuget.org/packages/Open.Evaluation.Arithmetic) and/or [Open.Evaluation.Boolean](https://www.nuget.org/packages/Open.Evaluation.Boolean), or take the [Open.Evaluation](https://www.nuget.org/packages/Open.Evaluation) metapackage for both.
